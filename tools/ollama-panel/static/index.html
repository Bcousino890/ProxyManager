        Token de GitHub

        Token con permiso repo (o fine-grained con «Contents: write») para subir la rama del pod. Se guarda solo en este pod (~/.pod-panel/github-token, permisos 600) y nunca en el repositorio.

        Búsqueda web completa

        Google, Bing y DuckDuckGo bloquean las IP de los pods. Con una clave gratuita de Tavily (1.000 búsquedas al mes en app.tavily.com) el agente busca en toda la web. Se guarda solo en este pod (~/.pod-panel/tavily-key).

        Publicación en GitHub

        El agente trabaja en una rama (nunca main directamente). «Integrar» lleva la rama a otra existente solo si es avance rápido (sin force).
